




Komponente:
 - Eine Komponente soll Abhängihkeiten von anderen komponenten(->Masterkomponenten) haben können
   - Wenn eine Komponente requested wird, dann werden die Masterkomponenten auch requested.
      - Erst wenn alle Masterkomponenten 'Ready' sind, dann kann die SubKomponente initialisiert werden
   - Eine Komponenete soll auch requested werden können von einem User oder vom System
 - Eine Komponente kann erst Disabled werden, wenn keine Request mehr bestehent.
 
 - Jede Masterkomponenten soll einen Traceback, von welcher komponete die gerade requested wird + User request (max. 16)
 - Jede Komponenete soll eine eindeutige nummer haben, 


Jede Komponentete hat die Hauptzustände (bitcodiert) 'NOT_READY (alle 0)', 'INITIALZED (bit0)', 'READY (bit1)', 'ERROR'(bit2)

Übergang: 'NOT_READY' ->  'INITIALZED': Init1(0)->Init2(1)->Init3(2)->Init4(3)
Übergang: 'INITIALZED' -> 'READY'     : Enable(4)
Übergang: 'READY' -> 'INITIALZED'     : Disable(5)
Übergang: 'INITIALZED' -> 'NOT_READY' : Deinit(6)

Komponente:
 - Eine Komponente soll Sub-Komponenten haben können -> MasterKomponente/SubKomponente
   - Eine Masterkomponente kann ersten den nächsten Step erreichen, wenn all Subkomponenten ihren Step abgeschlossen haben
   - Masterkomponenten haben einen 1ms Callback

 - Sequenzen: Init1(0)->Init2(1)->Init3(2)->Init4(3)->Enable(4)<->Disable(5)->Deinit(6)
                 |          |        |        |                                  |
                 |          |        |        \--------------------------------->|
                 |          |        \------------------------------------------>|
                 |          \--------------------------------------------------->|
                 \<------------------------------------------------------------->/

Init1: Low Level Initialisieren der Komponente: HW, DMA, peripherie, PIN
Init2: Gegebenfalls HW/SW Reset der Komponente
Init3: Istzustand erfassen: z.B. Read all Register bei seriellen Sensoren
Init4: Initialisierung
Enable: Schaltet die Komponente ein, z.B. DisplayEin, OutputOn
Disable: Schaltet die Komponente aus, z.B. DisplayAus, OutputOff
         Disable muss warten, bis die Komponente dafür bereit ist, keine laufenden Vorgänge, z.B. Kommunikation
DeInit: Low Level De-Initialisieren der Komponente: HW, DMA, peripherie, PIN
